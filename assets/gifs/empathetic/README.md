# Empathetic Emotion GIFs

This folder should contain GIFs for the "empathetic" emotion:
- `low.gif` - Low intensity empathetic response
- `medium.gif` - Medium intensity empathetic response  
- `high.gif` - High intensity empathetic response
- `placeholder.png` - Static fallback image

## Emotion Guidelines
Empathetic GIFs should convey:
- Understanding and validation
- "I hear you" feeling
- Warmth and compassion
- Gentle acknowledgment

## Recommended Sources
- Lottie animations converted to GIF
- GIPHY (search: "understanding", "support", "compassion")
- Custom-created animations matching the app's teal/blue color palette
