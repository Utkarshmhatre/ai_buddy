# Thoughtful Emotion GIFs

This folder should contain GIFs for the "thoughtful" emotion:
- `low.gif` - Low intensity thoughtful response
- `medium.gif` - Medium intensity thoughtful response  
- `high.gif` - High intensity thoughtful response
- `placeholder.png` - Static fallback image

## Emotion Guidelines
Thoughtful GIFs should convey:
- Reflection and consideration
- "Let's think about this" feeling
- Curiosity
- Contemplation

## Recommended Sources
- Lottie animations converted to GIF
- GIPHY (search: "thinking", "contemplating", "pondering")
- Custom-created animations matching the app's teal color palette
