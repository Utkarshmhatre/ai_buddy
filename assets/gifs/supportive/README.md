# Supportive Emotion GIFs

This folder should contain GIFs for the "supportive" emotion:
- `low.gif` - Low intensity supportive response
- `medium.gif` - Medium intensity supportive response  
- `high.gif` - High intensity supportive response
- `placeholder.png` - Static fallback image

## Emotion Guidelines
Supportive GIFs should convey:
- Comfort and presence
- "I'm here for you" feeling
- Warmth and safety
- Unconditional support

## Recommended Sources
- Lottie animations converted to GIF
- GIPHY (search: "hug", "support", "comfort")
- Custom-created animations matching the app's coral/warm color palette
