# Encouraging Emotion GIFs

This folder should contain GIFs for the "encouraging" emotion:
- `low.gif` - Low intensity encouraging response
- `medium.gif` - Medium intensity encouraging response  
- `high.gif` - High intensity encouraging response
- `placeholder.png` - Static fallback image

## Emotion Guidelines
Encouraging GIFs should convey:
- Motivation and hope
- "You can do it" feeling
- Gentle energy
- Supportive strength

## Recommended Sources
- Lottie animations converted to GIF
- GIPHY (search: "motivational", "cheer", "encouragement")
- Custom-created animations matching the app's sage green color palette
