# Calm Emotion GIFs

This folder should contain GIFs for the "calm" emotion:
- `low.gif` - Low intensity calm response
- `medium.gif` - Medium intensity calm response  
- `high.gif` - High intensity calm response
- `placeholder.png` - Static fallback image

## Emotion Guidelines
Calm GIFs should convey:
- Peace and tranquility
- Relaxation
- Soothing presence
- Gentle breathing

## Recommended Sources
- Lottie animations converted to GIF
- GIPHY (search: "zen", "peaceful", "breathing", "calm")
- Custom-created animations matching the app's lavender color palette
