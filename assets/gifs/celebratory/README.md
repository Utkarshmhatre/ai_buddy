# Celebratory Emotion GIFs

This folder should contain GIFs for the "celebratory" emotion:
- `low.gif` - Low intensity celebratory response
- `medium.gif` - Medium intensity celebratory response  
- `high.gif` - High intensity celebratory response
- `placeholder.png` - Static fallback image

## Emotion Guidelines
Celebratory GIFs should convey:
- Joy and pride
- Achievement recognition
- Happiness (not overwhelming)
- Gentle celebration

## Recommended Sources
- Lottie animations converted to GIF
- GIPHY (search: "congrats", "yay", "celebrate")
- Custom-created animations matching the app's warm amber color palette
